# JobHue

LinkedIn iş aramasında kartları **yeni**, **görüntülenen** ve **başvurulan** olarak renklerle ayırır. Chrome Web Store’a gitmez; açık kaynak olarak yayınlanır.

![JobHue](icons/icon128.png)

## Ne işe yarar

- Yeni ilanlar net kalır
- Baktığın ilanlar yumuşar
- Başvurduğun ilanlar ayrı bir renkle işaretlenir
- İstersen kategorileri gizlersin, opaklığı anlık değiştirirsin

LinkedIn’in kendi “Görüntülendi / Başvuruldu” etiketlerini de okur. Kart düzenini bozmaz.

## Kurulum

1. Bu repoyu klonla veya ZIP olarak indir
2. Chrome’da `chrome://extensions` sayfasını aç
3. Geliştirici modunu aç
4. **Paketlenmemiş öğe yükle** ile proje klasörünü seç

## Kullanım

LinkedIn → İş ilanları. Kartlar boyanır, sağ altta lejant görünür. Eklenti ikonuna tıklayınca gizleme, opaklık, etiket ve lejant ayarları açılır.

## Gizlilik

Veri dışarı gitmez. İş ilanı kimlikleri yalnızca tarayıcındaki `chrome.storage.local` içinde tutulur.
